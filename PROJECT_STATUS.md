## 🌟 Portfolio Overview & 3D Experience

A luxury dark-themed **3D Interactive Developer Portfolio** showcasing core software engineering, systems architecture, GenAI solutions, and client UI/UX productions.

### 🔮 3D Visual Engine
- **Three.js WebGL Particle Universe**: 900+ multi-hued kinetic particles reacting to scroll depth, mouse coordinates, and cursor velocity.
- **Floating 3D Polyhedrons & Orbital Rings**: Interactive gold/cyan wireframe icosahedrons and octahedrons that track cursor velocity with smooth lerping.
- **3D Card Perspective Tilt**: Tactile mouse parallax (`perspective(1000px) rotateX/rotateY`) across project and experience cards.

## 💻 Developer Commands

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build production bundle
npm run build

# 4. Deploy to GitHub Pages
npm run deploy

# 5. Deploy to Vercel
npx vercel --prod --yes
```
